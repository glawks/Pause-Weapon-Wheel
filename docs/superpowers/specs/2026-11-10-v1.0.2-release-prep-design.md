# v1.0.2 release preparation

**Intent:** Prepare a tested v1.0.2 build for OpenRAC's repository-based update mechanism, without publishing a release.

**Scope:** Only the `testing` branch. Keep the mod ID, saved settings, gameplay behavior and license intact. Set manifest and native module to the same version, declare the already-registered hooks, and publish a SHA256SUMS file with the Windows archive when a future tag is released.

**Design:** Follow the existing single-platform Windows workflow. Calculate a checksum over the final ZIP in `dist/`, verify it against the actual archive, upload it as a workflow artifact and include it in the GitHub Release. Do not create a tag or change `main` yet.

**Approaches:** The upstream SDK has a multi-platform template and checksum merge stage, but adopting the whole template would expand scope. Extend the existing Windows workflow instead, retaining its current manual and tag release mechanisms.

**Not included:** macOS/Linux binaries, automatic merges, editing author credits, or any OpenRAC registry submission. In-game graphics changes are already user-tested and need not be modified.

**Acceptance:** Consistent v1.0.2 metadata; all hooked function IDs declared and accepted by SDK 1.14.2; no release from ordinary branch pushes; a successful Windows build with a matching checksum file; and both `main` and v1.0.1 unchanged.
